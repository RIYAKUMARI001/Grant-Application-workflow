How to Fix Duplicate Emails

  1. Identify users with duplicate emails (check the warning banner above or look for the "DUP" badge)
  2. Decide which account to keep for each email - usually the most recent or most active one
  3. Delete duplicate accounts using the trash icon in the actions column
  4. Run migration command for the project once all duplicates are resolved:
    $ python manage.py makemigrations
    $ python manage.py migrate
